# @yz13/icons

Компоненты генерируются из `icons/*.svg` и экспортируются по имени:

```tsx
import { SearchIcon } from "@yz13/icons";

<SearchIcon size={20} aria-label="Поиск" />;
```

`size` задаёт ширину и высоту одновременно; по умолчанию это `24`. Компоненты также принимают остальные SVG-свойства и `ref`. Цвет наследуется через `currentColor`. Без `aria-label` или `aria-labelledby` иконка скрыта от скринридера; кнопке только с иконкой задавайте доступное имя на самой кнопке.

Сырые файлы доступны как `@yz13/icons/svg/search`, индекс — как `@yz13/icons/metadata`. До публикации запускайте `bun run build` в корне репозитория и подключайте `packages/react` как локальный пакет, например через запись `"@yz13/icons": "file:/путь/к/icons/packages/react"` в зависимостях проекта. Первые шесть рисунков приняты для начального выпуска.

Компоненты, исходные SVG и метаданные пакета распространяются по лицензии MIT; её текст входит в npm-архив.

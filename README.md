# @yz13/icons

Собственный набор иконок. SVG и метаданные в этом репозитории — единственный редактируемый источник React-пакета. Публичный каталог будет собираться отдельно из опубликованной версии пакета.

## Предпросмотр

```sh
bun run validate
bun run preview
```

После второй команды откройте `preview/index.html` в браузере. Файл самодостаточный: ему не нужен сервер или `@yz13/ui`. В PR такой же лист можно скачать из артефактов проверки `Check`.

Для сравнения изменённых SVG с другой копией репозитория запустите `bun run preview --base /путь/к/копии`. Если в ней есть иконка с тем же именем, лист покажет версии «до» и «после».

## Проверки

`bun run check` проверяет SVG и метаданные, запускает Oxlint и Oxfmt, собирает React-пакет и проверяет его публичные типы. Для исправления форматирования используйте `bun run format`.

## React-пакет

`bun run build` создаёт локальный пакет в `packages/react/dist`: генератор преобразует исходные SVG в React-компоненты и типы, Rolldown собирает отдельные ESM-модули для каждой иконки и общий индекс. Его можно подключить к React-проекту как локальную `file:` зависимость от `packages/react`; после публикации — установить `@yz13/icons` из npm. Именованные импорты, SVG и метаданные описаны в [документации пакета](packages/react/README.md).

Первые шесть SVG приняты для начального выпуска. До публикации они доступны только в локальной сборке пакета. Визуальные правила закреплены в [CONTRIBUTING.md](CONTRIBUTING.md); каталог появится отдельным этапом.

SVG, метаданные, React-компоненты и код репозитория распространяются по [лицензии MIT](LICENSE). Внешние изображения не включаются автоматически: происхождение каждого рисунка указывается в PR.

Правила для участников находятся в [CONTRIBUTING.md](CONTRIBUTING.md), история набора — в [CHANGELOG.md](CHANGELOG.md). Локальные инструкции агентам и skills для рисунка, ревью и выпуска лежат в `AGENTS.md` и `.agents/skills/`.

Процесс первого выпуска и публикации через Trusted Publisher описан в [docs/RELEASING.md](docs/RELEASING.md).
